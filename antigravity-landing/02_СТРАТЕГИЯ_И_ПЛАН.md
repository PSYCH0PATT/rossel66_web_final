# Стратегия и последовательность действий

## Что мы строим

Анимированный одностраничный лендинг для **ROSSEL 66 MUSIC** — музыкального лейбла.

### Визуальная ДНК (из референсов)
- **twinbru.com** → чёрный/тёмный фон, крупная типографика, полноэкранные секции, кинематографичность
- **jasminegunarto.com** → выразительный scroll-based storytelling, смелые переходы, кастомный курсор
- **oryzo.ai** → юмор + глубина, горизонтальный скролл, "sticky" секции, нарратив через скролл

### Эстетика 2026
- **Dark luxury** — глубокий чёрный с акцентами (золото, фиолетовый, или кислотный)
- **Kinetic typography** — заголовки живут, двигаются, реагируют
- **Scroll-driven animations** — каждый пиксель прокрутки что-то делает
- **Grain texture** — лёгкий шум поверх фонов (как у многих топ-сайтов 2025-2026)
- **Magnetic cursor** — кастомный курсор с притяжением к элементам

## Типографика (фирменная — те же шрифты что в дашборде)

- **Display/Заголовки:** `Syncopate` — файл `SyncopateRus.ttf` (уже есть в `/public/fonts/`)  
  Строгий, геометрический, всегда uppercase, широкий letter-spacing.  
  Использовать для: Hero headline, всех section titles (h1, h2)
- **Body/UI:** `Nunito Sans` (Google Fonts) — весь остальной текст
- **Нельзя:** Space Grotesk, Inter, Bebas Neue и другие "чужие" шрифты для заголовков

## KPI — как понять что получилось хорошо

- Лендинг загружается за < 3 сек
- Все анимации плавные (60fps)
- Работает на мобиле (iOS Safari + Chrome Android)
- Секции логично переходят друг в друга
- Есть "вау-эффект" в первые 5 секунд
