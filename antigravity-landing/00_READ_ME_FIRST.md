## Быстрый старт (5 шагов)

1. Скачай и установи Antigravity с https://antigravity.google/
2. Создай новый воркспейс → укажи **пустую** папку (не этот проект Next.js!)
3. Выбери модель: **Gemini 3.1 Pro** для основной работы
4. Открой `03_tasks.md` → скопируй содержимое → отправь агенту как первое сообщение
5. Дальше следуй промтам из `06_ПРОМТЫ_ПО_ПОРЯДКУ.md`

## Важно

- Antigravity создаёт **отдельный** React-проект, не трогает твой Next.js
- Итоговый лендинг: статичный HTML/CSS/JS или React — на твой выбор
- Весь процесс займёт **2–4 часа** при правильном подходе
