# Итерации, фиксы и работа с Browser Subagent

## Что делать если агент накосячил

### Проблема: Агент "поехал" и делает что-то не то
**Симптомы:** Пишет много кода который не просили, меняет не те файлы, уходит в сторону.

**Решение:**
```
Stop. Let's reset.

Please look at @tasks.md and tell me:
1. Which tasks are completed?
2. What exactly are you working on right now?
3. What is the next task?

Do not write any code. Just confirm current status.
```

---

### Проблема: Визуал совсем не то что хотелось
**Симптомы:** Выглядит как Bootstrap, светлый дизайн, обычные компоненты.

**Решение:**
```
This doesn't match our design system. Please:
1. Take a screenshot of the current state
2. Identify: which elements use wrong colors / fonts / spacing?
3. The background should be #050505 (near black), NOT white or light gray
4. Check @design/design-tokens.md and align ALL components with those tokens
5. Particularly fix: [назови конкретный элемент]
```

---

### Проблема: Анимации не работают или ломают layout
**Симптомы:** Страница прыгает, элементы пропадают, GSAP ошибки в консоли.

**Решение:**
```
The GSAP animations are causing layout issues. Let's debug:

1. Open browser console and show me all errors
2. For the problematic section, temporarily comment out all GSAP code
3. Verify the section looks correct without animations
4. Re-add animations one by one, starting with the simplest (opacity only)
5. The horizontal scroll in Services section should only activate on desktop:
   const isDesktop = window.innerWidth > 768
   if (isDesktop) { /* initialize horizontal scroll */ }
```

---

### Проблема: Мобильная версия сломана
**Симптомы:** Текст выходит за экран, горизонтальный скролл на мобиле, элементы перекрываются.

**Решение:**
```
Open browser subagent at viewport 375px width.
Take a screenshot.

I see these specific issues: [опиши что видишь]

Fix them with these priorities:
1. No horizontal overflow (add overflow-x: hidden to body)
2. Text never smaller than 14px
3. Padding on all sections: min 24px horizontal on mobile
4. Services section: convert to vertical stack with CSS
   @media (max-width: 767px) { /* vertical layout */ }
```

---

### Проблема: Build падает с ошибками TypeScript
**Симптомы:** npm run build выдаёт красные ошибки.

**Решение:**
```
The build is failing. Show me the full error output.

Common fixes:
- If "any" type warnings: add // @ts-ignore before the line or fix the type
- If missing imports: check that all components are properly imported in App.tsx
- If GSAP types: run npm install --save-dev @types/gsap if needed
- If module not found: verify all npm packages are installed

Run: npm run build 2>&1 | head -50
Show me the first 50 lines of the error.
```

## Работа с Browser Subagent — советы

### Как запросить скриншот
```
Ask browser subagent to:
1. Navigate to http://localhost:5173
2. Wait 2 seconds for animations to complete
3. Take a full-page screenshot
4. Also take a screenshot at viewport width 375px (mobile)
```

### Как запросить видео
```
Ask browser subagent to:
1. Navigate to http://localhost:5173
2. Wait for page load animation to complete
3. Record a video: slowly scroll from top to bottom (take ~8 seconds)
4. Save as artifact "full-page-walkthrough"
```

### Как протестировать конкретную секцию
```
Ask browser subagent to:
1. Navigate to http://localhost:5173/#услуги
2. Take a screenshot of the Services section in its initial state
3. Scroll slowly through it while recording
4. Report: does the horizontal scroll work? Does it feel smooth?
```

### Как протестировать hover-эффекты
```
Ask browser subagent to:
1. Navigate to http://localhost:5173
2. Hover over the "Отправить заявку" button — take screenshot
3. Hover over an artist card — take screenshot
4. Hover over a nav link — take screenshot
Report: do hover effects work as designed?
```

## Как переключать модели под разные задачи

| Задача | Модель | Почему |
|--------|--------|--------|
| Архитектура, planning | Gemini 3.1 Pro | Думает системно, хорошо планирует |
| Сложные GSAP анимации | Claude Sonnet 4.6 | Лучше понимает JavaScript timing |
| CSS правки, мелкие фиксы | Gemini 3.1 Fast | Быстро и достаточно точно |
| Очень сложная логика | Gemini 3.1 Pro или Claude Sonnet 4.6 | Оба хороши для сложного |
| Весь проект с нуля за раз | Gemini 3.1 Pro | Лучший баланс качества/скорости |

### Как переключить модель в Antigravity
В верхней части чата/Agent Manager → dropdown с названием модели → выбери нужную.
