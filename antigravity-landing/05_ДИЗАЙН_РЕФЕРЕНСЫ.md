# Дизайн-референсы и визуальная ДНК

## Главные референсы

### 1. twinbru.com — Темнота и кинематография
**URL:** https://www.twinbru.com

**Что взять:**
- Глубокий тёмный фон (#050505 или чистый чёрный)
- Крупная, смелая типографика на весь экран
- Полноэкранные секции с чёткими переходами
- Продуктовые "reveal" анимации при скролле
- Минимальный UI — текст и контент главенствуют
- Высококонтрастные изображения/элементы на тёмном фоне

**Код настроения:** luxury, editorial, cinematic

---

### 2. jasminegunarto.com — Scroll storytelling и выразительность
**URL:** https://jasminegunarto.com

**Что взять:**
- Scroll как нарратив — каждая секция рассказывает историю
- Kinetic typography — заголовки появляются по словам/буквам
- Смелые, нестандартные переходы между секциями
- Кастомный курсор с трансформацией при ховере
- Layered анимации — несколько элементов входят с разным timings
- Использование негативного пространства как дизайн-элемента
- Горизонтальные или диагональные акцентные линии

**Код настроения:** expressive, motion-first, portfolio-grade

---

### 3. oryzo.ai — Нарратив через скролл и depth
**URL:** https://oryzo.ai

**Что взять:**
- Sticky scroll sections — контент "прилипает" пока разворачивается история
- Параллакс слои на фоне
- Humor через копирайтинг (но адаптировать под серьёзный лейбл)
- "Wham" блоки — резкие контрастные секции разбивают монотонность
- Counter/stats анимации при появлении в viewport
- Горизонтальный скролл для перечисления карточек

**Код настроения:** narrative, depth, interactive

## Мудборд: конкретные элементы для нашего лендинга

### Hero секция
```
Вдохновение: twinbru.com hero + jasminegunarto.com typography
- Фон: тёмный (#050505) с очень медленным движением фоновых orb-ов (CSS radial gradients)
- Поверх фона: grain texture overlay (SVG noise filter, opacity 0.04)
- Заголовок: "ROSSEL 66 MUSIC" — очень крупный, буква за буквой появляется
- Анимация: SplitText по символам, stagger 0.03s, slide up from clip-path
- Подзаголовок: fade in после заголовка, задержка 0.5s
- CTA: кнопка с золотым border, hover — заполняется золотом
```

### Stats секция
```
Вдохновение: oryzo.ai stats blocks
- Фон: чуть светлее (#0d0d0d)
- Числа: count-up анимация при появлении в viewport (Intersection Observer)
- Карточки: glass-morphism (rgba белый бордер, backdropblur)
- Hover на карточке: поднимается на 4px + тень увеличивается
```

### Services секция
```
Вдохновение: oryzo.ai horizontal scroll
- Горизонтальный скролл на десктопе (GSAP ScrollTrigger horizontal pin)
- На мобиле: вертикальный стек
- Карточки: тёмный фон, золотой иконка, hover — лёгкое свечение
```

### Partners секция
```
Вдохновение: бегущая строка тик-токов и музык сайтов
- Две строки с бесконечным marquee-эффектом (CSS animation или JS)
- Первая строка: слева → направо
- Вторая строка: направо → влево
- Стиль: просто текст с разделителями "·" или "×", mono-шрифт
```

### Artists секция
```
Вдохновение: twinbru.com product cards
- Крупные карточки с минималистичным дизайном
- Имя артиста крупно, achievement текст мелко
- Hover: лёгкий золотой border появляется
- 4-я карточка (CTA): выделена пунктирным border, другой цвет фона
```

### Contact форма
```
Вдохновение: minimalist forms
- Максимально минималистичная — только линии, нет box-border
- Input underline style
- Focus: золотая линия снизу
- Submit: полная ширина кнопка, золотой accent
```

## Нельзя делать (анти-паттерны для этого проекта)

- ❌ Светлый/белый фон — не соответствует эстетике
- ❌ Bootstrap-style карточки с border-radius 8px и shadow
- ❌ Стандартные Material UI / Ant Design компоненты
- ❌ Clipart или emoji иконки
- ❌ Тяжёлые изображения без lazy-loading
- ❌ Анимации только на CSS transition: all (слишком дёргано)
- ❌ Текст мелче 14px на мобиле
- ❌ Секции без достаточного padding/whitespace

## Фирменные цвета лейбла (обязательно использовать)

Это реальные акцентные цвета бренда ROSSEL 66, используемые в личном кабинете лейбла:

```css
--accent-emerald: #00C957;     /* изумрудный — основной акцент */
--accent-emerald-2: #10b981;   /* изумрудный приглушённый */
--accent-azure: #0ea5e9;       /* лазурный — вторичный акцент */
--accent-cyan: #00CCCC;        /* циановый — тёмный вариант лазурного */
```

**Правила применения:**
- Изумрудный → CTA кнопки, hover-эффекты, активные состояния, borders при hover
- Лазурный → иконки, ссылки, вторичные подсветки, badges
- Градиент → `linear-gradient(135deg, #00C957, #0ea5e9)` для особых акцентов
- НЕ использовать как фон на больших площадях — только акценты

## Фирменная типографика лейбла (обязательно использовать)

Шрифты должны быть **строгие, геометричные, с характером**.

### Display / Заголовки — Syncopate
- Это основной заголовочный шрифт личного кабинета ROSSEL 66
- Файл: `SyncopateRus.ttf` — кастомная версия с кириллицей
- Характер: геометрический, угловатый, строгий, всегда UPPERCASE
- Применение: hero headline, все section titles (h1, h2)
- Всегда с `text-transform: uppercase` и широким `letter-spacing`

### Body — Nunito Sans
- Весь остальной текст: body copy, nav links, форма, подписи
- Google Fonts: `Nunito Sans`, weights 400/500/600/700
- Характер: читабельный, нейтральный, современный

**Нельзя:** Inter, Space Grotesk, и другие "популярные" шрифты — они не соответствуют идентичности бренда.

## Prompt для визуального tone-setting агенту

Используй этот абзац в начале каждого дизайн-промта:

```
The visual language: strict dark luxury meets independent music culture. 
Think: late-night recording studios, raw ambition, geometric precision.
Color palette: near-black backgrounds (#050505), emerald accents (#00C957), 
azure energy (#0ea5e9), near-white text (#F5F5F0). 
Typography: STRICT and geometric — Syncopate (custom font, file: SyncopateRus.ttf) 
for ALL display/section headings (always uppercase, wide letter-spacing), 
Nunito Sans for body text. No soft or rounded display fonts.
Every animation should feel intentional, not decorative.
Reference aesthetic: twinbru.com's cinematics + jasminegunarto.com's kinetic scroll + oryzo.ai's narrative depth.
```
