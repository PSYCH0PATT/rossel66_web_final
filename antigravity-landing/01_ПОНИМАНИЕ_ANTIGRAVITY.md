# Как работает Google Antigravity — полное понимание

## Что это такое

Google Antigravity — это AI-driven IDE (форк VS Code) от Google. Это **не** no-code визуальный редактор. Это агентная среда, где ты даёшь задачи на естественном языке, а AI-агент сам пишет код, запускает команды в терминале, открывает браузер, кликает по странице, делает скриншоты и продолжает итерировать.

**Ключевая метафора:** ты — Архитектор и Менеджер. Агент — Junior Dev, который не спит.

---

## Компоненты системы

### 1. Agent Manager (Mission Control)
Главная панель где ты:
- Создаёшь воркспейсы (=папки проектов)
- Ведёшь чат с агентом
- Видишь Artifacts (скриншоты, видео, диффы кода, таск-листы)
- Переключаешь модели

### 2. Browser Subagent
Специальный агент с доступом к браузеру. Он:
- Открывает localhost с твоим проектом
- Делает скриншоты того что видит
- Записывает короткие видео-walkthrough'ы
- Кликает по элементам для проверки интерактивности
- Возвращает визуальную обратную связь основному агенту

**Как включить:** при первом запуске Antigravity предложит установить Chrome extension — соглашайся.

### 3. Planning Mode (Режим планирования)
Агент генерирует детальный план реализации **перед** тем как написать код. Ты можешь:
- Прочитать план
- Поправить его
- Только потом дать OK на реализацию

**Используй для:** крупных изменений, новых секций, переработки архитектуры.

### 4. Fast Mode
Агент сразу начинает кодить без предварительного плана.

**Используй для:** мелких правок CSS, замены текста, небольших анимационных твиков.

### 5. Artifacts
Все результаты работы агента сохраняются как Artifacts:
- `tasks.md` — чеклист задач (автоматически обновляется)
- Скриншоты до/после
- Видео браузерных walkthrough'ов
- Code diffs

## Поддерживаемые модели

| Модель | Лучше для | Скорость | Качество кода |
|--------|-----------|----------|---------------|
| **Gemini 3.1 Pro** | Основная разработка, архитектура | Средняя | Отличное |
| **Gemini 3.1 Medium** | Итерации, правки | Быстрая | Хорошее |
| **Gemini 3.1 Fast** | Мелкие правки, CSS | Очень быстрая | Среднее |
| **Claude Sonnet 4.6** | Сложная логика, анимации | Средняя | Отличное |
| **Claude Opus 4.6** (если доступен) | Самые сложные задачи | Медленная | Превосходное |

### Рекомендация для твоего проекта:
- **Фаза 1 (архитектура + structure):** Gemini 3.1 Pro
- **Фаза 2 (анимации + интерактив):** Claude Sonnet 4.6
- **Фаза 3 (быстрые правки):** Gemini 3.1 Fast или Medium

## Техстек который генерирует Antigravity

По умолчанию: **React + TypeScript + Tailwind CSS**

Для анимированного лендинга 2026 также попроси подключить:
- **GSAP** — профессиональные анимации, ScrollTrigger
- **Framer Motion** — React-анимации
- **Lenis** — smooth scroll
- **Three.js** (опционально) — WebGL эффекты

## Workflow: правильный порядок

```
1. tasks.md → агент → утверждение плана
2. Scaffolding → базовая структура проекта
3. Секция за секцией → Hero → Facts → Services → ...
4. После каждой секции: скриншот → оценка → правки
5. Анимации → добавляются поверх готовой структуры
6. Responsiveness → мобильная адаптация
7. Финальный проход → полировка
```

## Золотые правила работы с Antigravity

1. **Один task за раз** — не давай агенту сделать всё и сразу
2. **Commit после каждой рабочей версии** — используй Git внутри воркспейса
3. **Planning Mode для больших изменений** — сначала план, потом код
4. **Скриншоты как фидбек** — после каждой итерации давай скриншот и говори что не так
5. **@file** — ссылайся на конкретные файлы в промтах для точности
6. **tasks.md** — это живой документ, агент его обновляет, ты его можешь редактировать
7. **.gitignore** — сразу игнорируй node_modules, .next, логи — меньше шума для агента

## Настройки Antigravity (Settings)

Включи сразу:
- ✅ Auto-open edited files
- ✅ Auto-continue (агент продолжает без паузы на рутинных шагах)
- ✅ Auto-lint fixes
- Terminal policy: **Allow common installs** (агент сам ставит npm пакеты)
- Review policy: **Ask for complex changes** (агент спрашивает только на крупных изменениях)

---

## Чего Antigravity НЕ умеет хорошо

- Генерировать уникальные изображения (используй Gemini Imagen отдельно или заглушки)
- Работать с закрытыми API без явных инструкций
- Понимать "сделай красиво" без конкретных референсов
- Самостоятельно поддерживать консистентный дизайн-токен систему (нужно явно прописывать)
