## Экстра-промты для итераций

### Если Hero выглядит скучно
```
The hero looks generic. Please make it more visually striking:
1. Add a very subtle animated text that continuously changes in the background (words related to music: ЗВУК · РИТМ · КУЛЬТУРА · МУЗЫКА), positioned behind the main headline, at 8% opacity, slowly scrolling upward, font Syncopate uppercase
2. Add a thin horizontal line separator between the eyebrow text and main headline that animates from width:0 to full width on load — use gradient #00C957 → #0ea5e9
3. The CTA button should have a subtle shimmer/gleam animation (moving highlight effect across the button), the glow should pulse in emerald #00C957
4. Consider adding a very faint waveform visualization (static SVG, just decorative) at the bottom of the hero before the scroll indicator — use color #00C957 at 15% opacity
```

### Если нужен более агрессивный/музыкальный вайб
```
The current design feels too corporate. Let's push the energy:
1. In the hero, after the main animation plays, add a looping subtle pulse animation on the headline (very slight scale 1.0 → 1.002 → 1.0, 4s loop) like a heartbeat
2. In the services section, add a decorative background element: large outlined text of the service number ("01", "02"...) positioned behind the card at 150% scale, opacity 0.03
3. Between every two sections, add a thin 1px horizontal divider line that draws itself (scaleX 0→1) as it scrolls into view
4. The artists section should have a noise/grain texture stronger on artist cards (opacity 0.06) for that lo-fi record aesthetic
```

### Если нужно поправить типографику
```
Typography audit and fix:
1. All section labels (like "01 — ДОСТИЖЕНИЯ") should use font-variant: tabular-nums and letter-spacing: 0.25em, font-size: 0.75rem, text-transform: uppercase
2. Section titles should have line-height: 1.1 (tight) and letter-spacing: -0.02em
3. Body text should be: font-size: 1rem, line-height: 1.65, color: rgba(245,245,240,0.7)
4. All number displays (stats) should use Space Grotesk with font-feature-settings: "tnum"
5. Make sure there's visual hierarchy: eyebrow → title → body should have clear size jumps
```

### Если анимации дёргаются
```
The animations feel janky/choppy. Please fix performance:
1. Add will-change: transform to all animated elements
2. Use transform: translate3d() instead of transform: translateY() for GPU acceleration
3. For all GSAP animations, ensure we're only animating transform and opacity (never width, height, top, left)
4. Add gsap.registerPlugin(ScrollTrigger) only once at the top level
5. On unmount, kill all ScrollTrigger instances to prevent memory leaks
6. For the marquee, use CSS animation instead of JS for better performance
```
