# Настройка переменных окружения

## 2captcha API ключ

Для работы парсеров Bandlink и VK с автоматическим решением капч необходимо настроить API ключ от 2captcha.com.

### 1. Получение API ключа

1. Зарегистрируйтесь на [2captcha.com](https://2captcha.com/enterpage)
2. Пополните баланс (минимум $1)
3. Получите API ключ в [настройках](https://2captcha.com/setting/api)

### 2. Настройка на сервере

Создайте файл `.env.local` в корне проекта:

```bash
# 2captcha API ключ для автоматического решения капч
TWOCAPTCHA_API_KEY=your_actual_api_key_here
```

**Замените `your_actual_api_key_here` на ваш реальный API ключ от 2captcha.**

### 3. Настройка на Linux сервере

Для production сервера добавьте переменную окружения:

```bash
export TWOCAPTCHA_API_KEY="your_actual_api_key_here"
```

Или в файле `.env`:
```bash
TWOCAPTCHA_API_KEY=your_actual_api_key_here
```

### 4. Проверка настройки

После настройки переменной окружения:

1. Перезапустите сервер
2. Запустите парсер Bandlink или VK
3. В логах должно появиться: `🔑 2captcha API ключ найден в переменных окружения`

### 5. Безопасность

- **НЕ** коммитьте файл `.env.local` в git
- **НЕ** передавайте API ключ через frontend
- Храните ключ только в переменных окружения сервера

### 6. Стоимость

- Yandex SmartCaptcha: ~$0.001-0.003 за решение
- VK капчи: ~$0.001-0.002 за решение
- Минимальный баланс: $1

### 7. Альтернативы

Если не хотите использовать 2captcha:
- Парсеры будут работать без автоматического решения капч
- При появлении капчи парсинг остановится
- Нужно будет решать капчи вручную
