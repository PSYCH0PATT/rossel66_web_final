# 🛡️ БЕЗОПАСНАЯ версия Bandlink Parser

## ⚠️ ВАЖНО: Защита от потери денег

Эта версия парсера создана с множественными уровнями защиты, чтобы предотвратить ситуацию с 7600+ запросами к 2captcha.

## 🔒 Уровни защиты:

### 1. **Лимит попыток решения капчи**
- Максимум **3 попытки** решения капчи за сессию
- После 3 неудачных попыток парсер останавливается
- Предотвращает бесконечные циклы

### 2. **Лимит запросов к 2captcha**
- Максимум **10 запросов** к 2captcha за сессию
- Счетчик увеличивается ПЕРЕД отправкой запроса
- Гарантирует, что не будет тысяч запросов

### 3. **Проверка результата**
- Проверяет, что токен получен от 2captcha
- Проверяет, что токен не пустой
- Логирует все ответы от 2captcha

### 4. **Правильный метод решения**
- Использует метод `yandexSmart` (не `coordinates`)
- Передает `sitekey` и `pageurl` (не скриншот)
- Вставляет токен в поле (не кликает по изображениям)

## 📊 Отличия от старой версии:

| Параметр | Старая версия | Безопасная версия |
|----------|---------------|-------------------|
| Метод решения | `coordinates` (неправильно) | `yandexSmart` (правильно) |
| Параметры | Скриншот изображения | `sitekey` + `pageurl` |
| Лимит попыток | Нет | 3 попытки |
| Лимит запросов | Нет | 10 запросов |
| Проверка результата | Слабая | Строгая |
| Логирование | Минимальное | Подробное |

## 🚀 Использование:

### 1. Установка зависимостей:
```bash
pip install selenium twocaptcha-python
```

### 2. Создание конфиг файла:
```json
{
  "target_artists": ["Artist Name"],
  "captcha_api_key": "your_2captcha_api_key"
}
```

### 3. Запуск:
```bash
python3 parsers/bandlink_parser_safe.py temp_bandlink_config.json
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ:

### 1. **Метод `yandexSmart` может быть недоступен**
- Стандартная библиотека `2captcha-python` может не поддерживать этот метод
- Нужно использовать библиотеку `2captcha-ts` (TypeScript)
- Или переключиться на Anti-Captcha

### 2. **Альтернативные решения:**

#### Вариант A: Использовать Anti-Captcha
```bash
pip install anticaptchaofficial
```

#### Вариант B: Использовать 2captcha-ts (Node.js)
```bash
npm install 2captcha-ts
```

#### Вариант C: Отказаться от автоматического решения капч
- Использовать куки авторизованного пользователя
- Парсить без капчи (если возможно)

## 🆘 Если что-то пошло не так:

1. **Проверьте логи** - все действия логируются
2. **Проверьте счетчики** - сколько запросов было отправлено
3. **Проверьте баланс 2captcha** - сколько денег потрачено
4. **Остановите парсер** - если видите подозрительную активность

## 💡 Рекомендации:

1. **Тестируйте на одном артисте** перед массовым парсингом
2. **Мониторьте баланс 2captcha** в реальном времени
3. **Используйте низкие лимиты** (3 попытки, 10 запросов)
4. **Проверяйте логи** после каждого запуска

## 🔧 Настройка лимитов:

Вы можете изменить лимиты в коде:
```python
self.max_captcha_attempts = 3  # Максимум попыток
self.max_captcha_requests = 10  # Максимум запросов
```
