# 🔑 Настройка 2captcha для автоматического решения капч

Этот проект интегрирован с сервисом [2captcha.com](https://2captcha.com) для автоматического решения:
- **Yandex SmartCaptcha** (Bandlink парсер)
- **VK Captcha** (VK парсер)

---

## 📋 **Шаг 1: Регистрация на 2captcha**

1. Перейдите на [2captcha.com](https://2captcha.com/enterpage)
2. Нажмите **"Регистрация"** или **"Sign up"**
3. Заполните форму:
   - Email
   - Пароль
   - Подтвердите email
4. Войдите в личный кабинет

---

## 🔑 **Шаг 3: Получение API ключа**

1. В личном кабинете перейдите в раздел **"Settings"** → **"API"**
   - Или прямая ссылка: https://2captcha.com/setting/api

2. Скопируйте **API Key** (выглядит примерно так):
   ```
   1dadad5f5bfe4dbb89a806b52118ad45
   ```

3. **Важно**: Не делитесь этим ключом с третьими лицами!

---

## ⚙️ **Шаг 4: Настройка в админ-панели**

1. Войдите в админ-панель вашего проекта
2. Перейдите в **"Плейлисты"** → **"Парсеры"**
3. Найдите поле **"🔑 2captcha API ключ"**
4. Вставьте ваш API ключ
5. Ключ автоматически сохранится в браузере (localStorage)

## 🎯 **Как это работает?**

### **Bandlink парсер (Yandex SmartCaptcha через метод Coordinates):**

```
1. Переходит на band.link/scanner
2. Обнаруживает Yandex SmartCaptcha
3. Делает скриншот капчи
4. Отправляет в 2captcha с методом "Coordinates" (клики по изображениям)
5. Получает координаты для кликов
6. Автоматически кликает по указанным координатам
7. Нажимает кнопку подтверждения
8. Продолжает парсинг
```

**Особенности:**
- ✅ **Полная автоматизация** - куки не требуются!
- ✅ **Метод Coordinates** - специально для Yandex SmartCaptcha
- 💰 **Стоимость**: ~$0.003-0.005 за одну капчу (немного дороже обычной капчи)
- ⏱️ **Время решения**: 20-60 секунд

### **VK парсер (VK Captcha):**

```
1. Переходит на страницу артиста VK
2. Если капча → автоматически решается через 2captcha
3. Продолжает парсинг
```

## 🔧 **Проверка работы**

### После настройки запустите тестовый парсинг:

1. В админ-панели выберите 1-2 артистов
2. Убедитесь что API ключ введен
3. Запустите **"Парсить Bandlink"** или **"Парсить VK"**
4. Следите за логами в консоли:
   ```
   🔑 2captcha API ключ предоставлен
   ✅ 2captcha инициализирован (API ключ: 1dadad5f...)
   🔍 Обнаружена капча!
   🔄 Отправляем капчу в 2captcha для решения...
   ⏳ Ожидаем решения от 2captcha (обычно 20-40 секунд)...
   ✅ Капча решена! Токен получен
   ✅ Парсинг завершен успешно
   ```

### Если видите ошибки:
- **"❌ Ошибка инициализации 2captcha"** → Проверьте правильность API ключа
- **"❌ Баланс исчерпан"** → Пополните баланс на 2captcha.com
- **"❌ Не удалось решить капчу"** → Попробуйте еще раз (редкая ошибка)
