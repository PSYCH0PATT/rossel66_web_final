# 🍪 Инструкция по кукам (для справки)

⚠️ **Эта инструкция оставлена только для справки. Bandlink парсер больше не использует куки.**

Если вам всё же нужны куки для других целей, вот как их получить:

---

## 📋 Инструкция для Google Chrome / Chromium

### 1. Установите расширение "EditThisCookie"
- Перейдите в [Chrome Web Store](https://chrome.google.com/webstore/detail/editthiscookie/fngmhnnpilhplaeedifhccceomclgfbg)
- Нажмите "Добавить в Chrome"

### 2. Откройте band.link в браузере
- Перейдите на https://band.link/scanner
- **Пройдите капчу вручную**, если она появилась
- Убедитесь, что страница полностью загружена

### 3. Экспортируйте куки
- Нажмите на иконку расширения "EditThisCookie" в панели инструментов
- Нажмите кнопку "Export" (иконка 🔽 внизу)
- Куки скопированы в буфер обмена

### 4. Сохраните куки в конфигурацию
Создайте или отредактируйте файл конфигурации для парсера:

```json
{
  "target_artists": ["Sour Diesel", "Artist Name 2"],
  "cookies": [
    {
      "domain": ".band.link",
      "expirationDate": 1735689599,
      "hostOnly": false,
      "httpOnly": false,
      "name": "cookie_name",
      "path": "/",
      "sameSite": "no_restriction",
      "secure": true,
      "session": false,
      "storeId": "0",
      "value": "cookie_value"
    }
  ]
}
```

**ВАЖНО**: Вставьте экспортированные куки в массив `"cookies": [...]`

## 📋 Альтернатива: Использование DevTools (без расширений)

### 1. Откройте DevTools
- Перейдите на https://band.link/scanner
- Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux) / `Cmd+Option+I` (Mac)
- Перейдите на вкладку "Application" (или "Приложение")

### 2. Экспортируйте куки
- В левой панели выберите "Storage" → "Cookies" → "https://band.link"
- Щелкните правой кнопкой мыши на любую куку → "Copy all as JSON"

### 3. Сохраните в конфигурацию
Вставьте скопированный JSON в поле `"cookies"` конфигурации.

## 🔄 Автоматическая передача куков через API

Если вы запускаете парсер через API (например, `/api/parsers/bandlink`), добавьте куки в тело запроса:

```json
{
  "target_artists": ["Sour Diesel"],
  "cookies": [
    // Ваши куки здесь
  ]
}
```

## ⚠️ Важные замечания

1. **Куки истекают**: Обычно срок действия куков ограничен (от нескольких дней до месяца). Если парсер снова начнет показывать капчу, обновите куки.

2. **Безопасность**: Не делитесь куками с третьими лицами! Куки содержат данные вашей сессии.

3. **Проверка куков**: 
   - Убедитесь, что в куках есть `domain: ".band.link"` или `domain: "band.link"`
   - Проверьте, что `secure: true` для HTTPS

4. **Формат для Selenium**:
   Парсер автоматически преобразует куки в формат, понятный Selenium:
   - `expirationDate` → `expiry`
   - Все остальные поля сохраняются

## 🧪 Тестирование

После добавления куков запустите парсер:

```bash
python3 parsers/bandlink_parser_production_linux.py config.json
```

Вы должны увидеть:
```
🍪 Загружаем 15 куков...
✅ Загружено 15/15 куков
```

Если куки не загрузились:
```
⚠️ Куки не найдены в конфигурации. Работаем без куков (возможна капча!)
```

## 📞 Поддержка

Если после добавления куков капча все еще появляется:
1. Убедитесь, что куки актуальные (экспортированы недавно)
2. Проверьте, что вы пропустили капчу вручную перед экспортом
3. Попробуйте обновить куки через несколько часов
