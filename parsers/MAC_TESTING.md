# 🍎 Mac Testing Environment для Bandlink Parser

## 📋 Описание

Этот набор файлов позволяет тестировать Bandlink парсер локально на Mac без необходимости деплоя на сервер.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Перейдите в папку parsers
cd parsers

# Создайте виртуальное окружение
python3 -m venv mac_test_env

# Активируйте виртуальное окружение
source mac_test_env/bin/activate

# Установите зависимости
pip install -r requirements_mac.txt

# Убедитесь, что у вас установлен Chrome
# Скачайте chromedriver: https://chromedriver.chromium.org/
```

### 2. Запуск теста

#### Быстрый способ:
```bash
# Запустите готовый скрипт
./test_mac.sh
```

#### Ручной способ:
```bash
# Активируйте виртуальное окружение
source mac_test_env/bin/activate

# Запустите тест
python3 run_mac_test.py
```

## 📁 Файлы

- **`bandlink_parser_mac.py`** - Mac-версия парсера (не headless)
- **`run_mac_test.py`** - Скрипт для запуска тестов
- **`bandlink_config_mac.json`** - Пример конфигурации
- **`MAC_TESTING.md`** - Эта инструкция

## 🔧 Отличия от Linux версии

### Mac-версия (`bandlink_parser_mac.py`):
- ✅ **НЕ headless** - браузер открывается визуально
- ✅ **Упрощенная имитация поведения** - без сложных движений мыши
- ✅ **Отдельная база данных** - `bandlink_playlists_mac.db`
- ✅ **Подробное логирование** - видно все этапы работы
- ✅ **Обработка ошибок** - более детальная диагностика

### Linux-версия (`bandlink_parser_linux.py`):
- ✅ **Headless режим** - работает без GUI
- ✅ **Полная имитация поведения** - сложные движения мыши
- ✅ **Оптимизирована для сервера** - минимальные ресурсы

## 🎯 Что тестируется

1. **Настройка Chrome драйвера** - проверка совместимости
2. **Переход на band.link** - доступность сайта
3. **Детект капчи** - обнаружение Yandex SmartCaptcha
4. **Решение капчи через 2captcha** - метод Coordinates
5. **Поиск артистов** - функциональность поиска
6. **Парсинг плейлистов** - извлечение данных
7. **Сохранение в БД** - работа с SQLite

## 🚨 Возможные проблемы

### 1. Chrome не найден
```
❌ Chrome WebDriver не работает: Message: 'chromedriver' executable needs to be in PATH
```
**Решение**: Установите chromedriver и добавьте в PATH

### 2. Selenium не установлен
```
❌ Selenium не установлен!
```
**Решение**: `pip install selenium`

### 3. 2captcha не работает
```
❌ 2captcha-python не установлен!
```
**Решение**: `pip install 2captcha-python`

### 4. Капча не решается
```
❌ Не удалось решить капчу автоматически!
```
**Проверьте**:
- Правильность API ключа 2captcha
- Баланс на 2captcha.com
- Интернет соединение
