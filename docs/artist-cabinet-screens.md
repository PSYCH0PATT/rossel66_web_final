# Описание всех экранов кабинета артиста

> Платформа: веб-приложение (личный кабинет) для музыкального лейбла ROSSEL.  
> Тема: тёмная.  
> Адаптивность: мобильные, планшеты, десктоп.

---

## Общий Layout

### Сайдбар (левая навигация)
- Логотип лейбла «ROSSEL» в шапке
- Пункты меню (секция «Личный кабинет»):
  - Главная
  - Релизы
  - Отчеты
  - Выплаты
  - Плейлисты
  - Аналитика
- Внизу: username артиста + пункт «Настройки»
- На мобильных — сайдбар скрыт, открывается по кнопке-гамбургеру

### Верхняя навигация
- Хлебные крошки (скрыты на мобильных)
- Логотип по центру на мобильных
- Аватарка пользователя справа с выпадающим меню (имя, роль, выход)

---

## 1. Главная (Dashboard)

**URL**: `/dashboard/artist/{username}/dashboard`

### Блок статистики — 4 карточки в ряд:

| Карточка | Значение | Подтекст |
|---|---|---|
| Всего релизов | число | «X выпущено, Y в процессе» |
| Отчеты | число | «Последний: Q3 2025» или «Нет отчетов» |
| Заработок | сумма ₽ | «За все время» |
| Плейлисты | число | «Промо-плейлисты» |

### Блок «Последняя активность»
- Лента последних 5 событий (релиз добавлен, плейлист найден, отчёт назначен, выплата и т.д.)
- Каждое событие: иконка + заголовок + описание + относительное время
- Внизу: 3 кнопки-ссылки — «Релизы», «Отчеты», «Выплаты»

---

## 2. Релизы (список)

**URL**: `/dashboard/artist/{username}/releases`

- Заголовок: «Релизы (N)»

### Пустое состояние:
- «Нет релизов» + «После публикации релизы появятся здесь.»

### Таблица релизов:
Колонки:

| Колонка | Описание |
|---|---|
| Обложка | Миниатюра 48×48 |
| Название | Кликабельная ссылка на детальную страницу |
| Исполнители | Основной артист + фиты |
| UPC | Моноширинный шрифт |
| Дата релиза | Формат ДД.ММ.ГГГГ |
| Статус | Бейдж: Модерируется / Отклонен / В доставке / Доставлен |
| Треков | Число |

---

## 3. Детальная страница релиза

**URL**: `/dashboard/artist/{username}/releases/{id}`

- Кнопка «← Назад к релизам»

### Лейаут: 2 колонки (1/3 + 2/3), на мобильных — 1 колонка

#### Левая колонка:
- Квадратная обложка релиза
- Название релиза
- Имя артиста
- UPC код, дата релиза, количество треков

#### Правая колонка — «Список треков»:
- Каждый трек: номер + название + ISRC + длительность

### Нижний блок — 2 карточки:

**«Техническая информация»:**
- ID релиза, UPC код, дата релиза

**«Статистика»:**
- Общее количество треков
- Треки с ISRC
- Общая длительность

---

## 4. Плейлисты

**URL**: `/dashboard/artist/playlists`

- Заголовок: «Мои плейлисты»
- Подзаголовок: «Все плейлисты, в которых есть ваши треки»

### Пустое состояние:
- «Пока нет плейлистов с вашими треками»
- «Плейлисты подгружаются из отчётов SFTP после синхронизации»

### Сетка плейлистов (адаптивная, от 2 до 8 колонок в зависимости от ширины экрана)

### Карточка плейлиста:
- Квадратная обложка. Кликабельная — открывает ссылку на плейлист в новой вкладке
- При наведении: иконка Play по центру обложки
- Название плейлиста (макс. 2 строки)
- Бейдж платформы (VK Музыка / Яндекс Музыка / МТС Музыка / Сбер Музыка)
- Название трека (если есть)

### Футер:
- «Всего найдено: N плейлист(ов)»

---

## 5. Детальная страница плейлиста

**URL**: `/dashboard/artist/{username}/playlists/{id}`

- Кнопка «← Назад к плейлистам»

### Лейаут: 2 колонки (1/3 + 2/3), на мобильных — 1 колонка

#### Левая колонка:
- Квадратная обложка с бейджем платформы поверх
- Название плейлиста
- Дата добавления
- Описание
- Кнопка «Открыть в {платформа}»

#### Правая колонка — «Информация о треке»:
- Если трек найден:
  - Название трека, из какого релиза, ISRC, длительность
  - Блок «О релизе»: UPC, дата релиза, статус, кол-во треков
  - Кнопка «Перейти к релизу»
- Если трек не найден: сообщение «Информация о треке не найдена»

---

## 6. Отчеты

**URL**: `/dashboard/artist/{username}/reports`

- Заголовок: «Отчеты»
- Переключатель годов (кнопки: 2024, 2025 и т.д.)

### Пустое состояние:
- «Отчеты для {имя артиста} пока не сгенерированы»

### Список отчетов (2 колонки, группировка по кварталам)

### Карточка отчёта:
- Иконка документа слева
- «Отчет за Q1 2025» + дата генерации/загрузки
- Статус подписи: «Подписан» / «Не подписан»
- Сумма в рублях
- 2 кнопки: Предпросмотр (открывает модальное окно) и Скачать

### Модальное окно предпросмотра:
- Заголовок «Предпросмотр отчета»
- Содержимое отчёта внутри

---

## 7. Выплаты и баланс

**URL**: `/dashboard/artist/{username}/payments`

- Заголовок: «Выплаты и баланс»

### Блок баланса — 3 карточки в ряд:

| Карточка | Значение | Подтекст |
|---|---|---|
| Общий баланс | сумма ₽ | «Накопленные средства» |
| Доступно к выплате | сумма ₽ | «Минимум: 3,000 ₽» |
| Выплачено | сумма ₽ | «За все время» |

### Предупреждение (если баланс > 0, но < 3000₽):
- «Недостаточно средств для выплаты»
- Текст: сколько накоплено, сколько осталось до минимума 3000₽

### История отчетов (все отчёты сразу, секция на период «квартал + год», от свежих к старым):

Каждая запись:
- Иконка статуса (выплачено/не выплачено)
- «Отчет за Q1 2025»
- Дата загрузки
- Статус подписи: «Подписан» / «Не подписан»
- Сумма справа + статус выплаты

### Пустое состояние:
- «У вас пока нет отчетов»

---

## 8. Аналитика стримов

**URL**: `/dashboard/artist/analytics`

- Заголовок: «Аналитика стримов»
- Подзаголовок: «Статистика прослушиваний ваших треков»

### Панель фильтров:
- Выпадающий список треков («Все треки» по умолчанию)
- Выбор периода: Неделя / 30 дней / 3 месяца / 6 месяцев / Год / Выбранный период
- При «Выбранный период»: два date-picker (От / До)
- Чип с общим количеством стримов

### Пустое состояние:
- «Нет данных»
- «Данные аналитики появятся после импорта»

### 4 графика (сетка 2×2, на мобильных — 1 колонка):

**«Стримы по площадкам»** — линейный XY-график, каждая площадка (DSP) — отдельная линия, ось X — даты, ось Y — стримы

**«Платные / Бесплатные стримы»** — 2 горизонтальных прогресс-бара с процентами

**«Прослушивания по трекам»** — горизонтальные бары с прокруткой, отсортированы по убыванию. Каждый бар: название трека + полоска + число

**«Стримы по источникам»** — горизонтальные бары, аналогично трекам

---

## 9. Настройки профиля

**URL**: `/dashboard/artist/{username}/settings`

- Заголовок: «Настройки профиля»

### Карточка «Информация профиля» (только для чтения):
- Имя артиста (подсказка: «Имя может изменить только администратор»)
- Email (подсказка: «Email может изменить только администратор»)
- Username

### Карточка «Аватарка профиля»:
- Текущая аватарка (круглая) или заглушка с первой буквой имени
- Зона drag & drop / выбора файла (PNG, JPG до 5MB)
- Кнопка «Сохранить аватарку»

### Карточка «Смена пароля»:
- Поля: текущий пароль, новый пароль (мин. 6 символов), подтверждение
- Кнопка «Обновить пароль»

### Алерты:
- Сообщение об успехе или ошибке внизу страницы

---

## 10. Страница логина

**URL**: `/dashboard/login`

- Центрированная карточка с логотипом лейбла
- Форма: логин + пароль + кнопка «Войти»
- После входа: артисты перенаправляются в свой кабинет, админы — в админку
