# Buildin CRM: скрытие диагностических колонок

Чеклист для владельца workspace (OpenSpec 7.4). Выполняется вручную в браузере Buildin после RU-rename свойств (задача 7.3).

Цель: в **рабочих** табличных видах CRM не показывать служебные ID и версию синхронизации. Данные остаются в схеме — их можно вернуть в вид при отладке.

## Какие колонки скрывать

| База | Скрыть по умолчанию |
|------|---------------------|
| Артисты (CRM) | Локальный ID, Версия синхр. |
| Релизы | Локальный ID, ID артиста, Версия синхр. |
| Треки | Локальный ID, Локальный ID релиза, ID заявки |
| Отчёты и выплаты | Локальный ID, ID артиста, Версия синхр. |

Отношения **АртистRel** / **РелизRel** не трогать (оставить видимыми, если уже в виде).

## Пошагово (для каждой CRM-базы)

1. Откройте нужную базу в Buildin (Артисты / Релизы / Треки / Отчёты).
2. Убедитесь, что открыт **вид по умолчанию** (Default / основной Table view), которым пользуется команда.
3. В шапке таблицы откройте меню колонок / свойств вида (иконка настроек вида или «Properties» / «Свойства»).
4. Снимите галочки с диагностических колонок из таблицы выше — колонки исчезнут из вида, но останутся в схеме базы.
5. Сохраните вид (если Buildin спрашивает «Save for everyone» / сохранить для всех — сохраните для всех участников).
6. Обновите страницу и проверьте: в таблице нет Локальный ID / Версия синхр. / ID артиста / ID заявки (где применимо).
7. Повторите шаги 1–6 для остальных трёх CRM-баз.

## Не делать

- Не удаляйте свойства из схемы базы — только скрывайте в виде.
- Не меняйте form_* очереди анкет и PII-базы в рамках этого чеклиста.
- Не переименовывайте свойства вручную — для этого есть `scripts/migrate-buildin-crm-ru-labels.ts`.

## Проверка после скрытия

- [ ] Артисты: вид без «Локальный ID» и «Версия синхр.»
- [ ] Релизы: вид без «Локальный ID», «ID артиста», «Версия синхр.»
- [ ] Треки: вид без «Локальный ID», «Локальный ID релиза», «ID заявки»
- [ ] Отчёты: вид без «Локальный ID», «ID артиста», «Версия синхр.»
- [ ] Рабочие поля (статус, ответственный, заметки, дедлайн и т.д.) по-прежнему видны
