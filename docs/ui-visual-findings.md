## Mobile: главное

- **Навигация сломана функционально**: бургер-drawer не скроллится — в админ-ЛК нижние пункты недостижимы (F-75); артист-часть «разлогиниться с телефона невозможно» — **[админ-контекст]** (реальный drawer rompy помещается впритык, риск латентный для вьюпортов <657px).
- **Широкие таблицы не адаптированы**: адм /payments вовсе без горизонтального скролла — тогглы «Выплачен» недостижимы (F-76); адм /releases и /activity прячут ключевые колонки (включая «Действия») за правым краем без индикатора; у артиста — таблица «Треки» на карточке релиза шире вьюпорта, «Длительность» скрыта, wheel не работает (F-77); переход по строке админ-таблиц — только вторым тапом (F-31; в артист-списке релизов rompy карточки кликабельны первым тапом — не воспроизводится).
- **Графики на таче**: тултип закрывает до половины плота и закрывается только тапом вне графика (F-19), остаётся открытым и «переезжает» при скролле (F-88); ось Y «0K» (F-05) и слипшиеся подписи X (F-62) воспроизводятся и на мобиле.
- **Тач-эргономика и подписи**: кнопка закрытия модалки 16×16 px (F-80), icon-only вкладки и кнопки без подписей (F-84, F-66), H1 переносится «РЕДАКТИРОВАНИ / Е» (F-83), заголовки событий усечены до ~14 символов (F-78).
- **Оговорка среды**: админ-порции фактически прогнаны на ~500 CSS px (min-width окна Chrome) — на честных 390 всё перечисленное усиливается; артист-ЛК проверен на 390 (F-08).
