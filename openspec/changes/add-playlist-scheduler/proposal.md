# Change: Автоматическое расписание парсинга плейлистов

## Why
Релизы выходят в ночь с четверга на пятницу в 00:00. Нужно автоматически парсить плейлисты для артистов с новыми релизами, чтобы отслеживать их попадание в плейлисты на платформах.

## What Changes
- Добавлено расписание автоматического парсинга через node-cron
- Пятница 00:30 МСК — первый скан через 30 минут после выхода
- Суббота 16:00 МСК — второй скан
- Воскресенье 16:00 МСК — третий скан
- Понедельник 16:00 МСК — четвёртый скан
- Парсятся только артисты с релизами за последние 7 дней
- Добавляются только новые плейлисты (дубликаты игнорируются)

## Impact
- Affected specs: `playlist-parsers`
- Affected code: `lib/scheduler.ts`, `app/api/cron/playlists/route.ts`
